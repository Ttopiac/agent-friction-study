# t-test: % dissatisfied messages per session

| Session type | n | M | SD |
|---|---|---|---|
| Text | 13 | 4.9 | 7.9 |
| Visual | 9 | 8.5 | 9.5 |

Visual sessions had more dissatisfied messages (*M* = 8.5%, *SD* = 9.5) than text sessions (*M* = 4.9%, *SD* = 7.9), but the difference was not significant, *t*(15.2) = 0.92, *p* = .371, *d* = 0.41.
