# Descriptive statistics: dissatisfied messages by domain

## Purpose
This analysis shows where friction occurs. It counts the dissatisfied messages in each domain.

## Variables
| Variable | Role | Definition |
|---|---|---|
| Dissatisfied message | Measure | A message with the tone Dissatisfied or Mixed. |
| Domain | Group | The kind of work in the message. See 0_definitions.md. |

## Table 1. Dissatisfied messages by domain
| Domain | Messages | Dissatisfied | % |
|---|---|---|---|
| Web page | 19 | 4 | 21.1 |
| Slide deck | 160 | 28 | 17.5 |
| Unclassified | 21 | 1 | 4.8 |
| Documents & email | 28 | 1 | 3.6 |
| Admin forms (B) | 33 | 1 | 3.0 |
| Tools & setup | 38 | 1 | 2.6 |
| Admin forms (A) | 46 | 1 | 2.2 |
| Research & code | 24 | 0 | 0.0 |

## Results
There were 369 messages. Of these, 37 (10.0%) were dissatisfied.
Web page had the highest rate (21.1%). Slide deck had the second highest rate (17.5%).
All other domains had a rate of 4.8% or less.

## Interpretation
Web page and Slide deck have 86% of all dissatisfied messages.

In these two domains, 82% of the messages are about visual output.

Thus, friction occurs mostly in visual work.

## Limitation
- This analysis is a description. It does not include a statistical test.
- The domains have different sizes (19 to 160 messages). The % for a small domain is not stable.
