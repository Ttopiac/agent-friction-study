# t-test: dissatisfied replies after visual vs text prompts

| Output type | n | M | SD |
|---|---|---|---|
| Text | 145 | 4.1 | 20.0 |
| Visual | 140 | 14.3 | 35.1 |

## Result
Visual prompts had more dissatisfied replies (*M* = 14.3%, *SD* = 35.1) than text prompts (*M* = 4.1%, *SD* = 20.0), and the difference was significant, *t*(218.9) = 2.98, *p* = .003, *d* = 0.36.

## Meaning
Output type matters: prompts about visual output were followed by a dissatisfied reply more often.

## Limitation
25 pastes have no output type and are left out. Prompts from the same session are not independent, and the outcome is yes/no, so the t-test compares percentages only approximately.
