# Definitions

friction.py makes this file from config/rules.json. Do not edit this file.
Patterns: `?` = the letter before it is optional. `\d+` = a number. `\w*` = the end of a word. `(a|b)` = a or b.

## Unit
One message that the user typed. The study does not include session summaries, interruption markers, commands, or pastes. A paste has more than 120 words, or it starts with one of these words: Hello, Hi, Dear, Hey.

## Session
A new session starts after a gap of more than 60 minutes. Session-level tests do not use sessions with fewer than 3 messages.

## Domain
The first list with a matching word sets the domain. If no word matches, the message gets the domain of the previous message in the same session. If there is no previous message, the domain is Unclassified. Groups: Project X = Admin forms (B), Web page, Slide deck.
- **Admin forms (A):** `register`, `enroll`, `course credit`, `internship course`, `professional course`, `dissertation`, `advisor`
- **Documents & email:** `resume`, `resume_all`, `stories`, `cover letter`, `job description`, `JD`, `apply for`, `job application`, `recruiter`, `interview`
- **Slide deck:** `slides?`, `talk`, `presentation`, `pages? \d+`, `citations?`, `pptx`
- **Web page:** `intro`, `introduction`, `page`, `website`
- **Admin forms (B):** `background check`, `drug`, `screening`, `onboarding`, `I-9`, `W-4`, `HR`, `direct deposit`
- **Research & code:** `spatial`, `DLPFC`, `GCN`, `benchmark`, `experiment`, `nicheformer`, `scGPT`, `re-run`, `run the experiment`
- **Tools & setup:** `install`, `claude`, `git`, `github`, `commit`, `push`, `repo`, `chrome`, `disappear`, `scroll`, `memory`

## Output type
The first list with a matching word sets the output type. If no word matches, the message gets the output type of the previous message in the same session. If there is no previous message, the output type is Text.
- **Visual:** `html`, `pptx`, `pdf`, `png`, `jpg`, `gif`, `slides?`, `pages? \d+`, `figures?`, `images?`, `font`, `colou?r`, `layout`
- **Text:** `txt`, `py`, `md`, `csv`, `tex`, `R`, `json`, `email`, `message`, `resume`, `cover letter`

## Tone
If both lists match, the tone is Mixed. If one list matches, the tone is the name of that list. If no list matches, the tone is Neutral. A dissatisfied message has one of these tones: Dissatisfied, Mixed.
- **Dissatisfied:** `bad`, `wrong`, `unclear`, `broken`, `unprofessional`, `not (good|professional|clear)`, `not as good`, `not a good`, `way too`, `too (small|big|long|short|light|general|many)`, `disappear\w*`, `(didn'?t|did not) (see|change|show|update)`, `you (didn'?t|did not)`, `still (different|broken|not)`, `does not look`, `doesn'?t look`, `not the same`, `looks the same`, `don'?t like`, `do not like`, `what happened`, `hate`, `drives? nuts?`, `oh my god`, `piss\w*`, `already said`, `why (my|all|did|do you)`
- **Satisfied:** `great`, `good job`, `nice`, `thanks?`, `thank you`, `cool`, `excellent`, `very good`, `much better`, `looks better`, `love`

## Reply
The study pairs each prompt with the next message that the user typed in the same session. A prompt is an included message or a paste, because the agent received the paste. The tone of the next message (Dissatisfied, Satisfied, or Neutral) shows the result of the agent's work on the prompt.

## Limits
Word lists do not find sarcasm or indirect complaints. Private word lists (names and organizations) stay on the local computer. This file does not show them.
